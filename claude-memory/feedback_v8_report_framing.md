For ABF3 v8 reporting, the main view = **Window B** (post-top-up, all treated ABF1 titles = the catalog as it actually runs). Window A results, projection-vs-measured calibration, and A-vs-B decompositions are **secondary → appendix**.

**Why:** Window B is the product/decision configuration — the full treated catalog. Window A's value is methodological (validates projection machinery, isolates causes), not the headline.

**How to apply:** In the v8 report and stakeholder communications, lead with Window B global/topline numbers; put Window A, calibration, and decomposition analyses in appendices. Related: [[project-v8-experiment]].
